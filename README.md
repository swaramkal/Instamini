# Subway Sprint

A lightweight browser game inspired by endless runner mechanics like Subway Surfers. It runs in the browser and is built with plain HTML, CSS, and JavaScript.

## Features

- 3-lane endless runner gameplay
- Left/right movement
- Jump controls
- Coin collection and score tracking
- Game-over and restart flow
- Best-score persistence in localStorage

## Run locally

1. Open the repository folder in a browser, or
2. Use a simple local web server:

```bash
python -m http.server 8000
```

Then open:

```text
http://localhost:8000
```

## Controls

- Left / Right arrow: switch lanes
- Up arrow / Space: jump
- Enter: restart after a crash

## Project files

- `index.html` – page structure
- `style.css` – visual theme and layout
- `game.js` – gameplay logic and rendering

This project is an original browser game inspired by the classic endless-runner format, not the proprietary commercial game code.
